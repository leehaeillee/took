# 툭 · TUK Android 테스트 APK

버전: 0.2.0-dev · Android 7.0(API 24) 이상 · ARM 32/64비트

[TUK-debug.apk 다운로드](https://github.com/leehaeillee/took/raw/refs/tags/apk-v0.2.0/TUK-debug.apk)

휴대폰에서 APK를 내려받아 열고, 요청되면 파일을 연 앱의 “알 수 없는 앱 설치”를 허용합니다. 0.1.0과 같은 키를 사용해 기존 앱 위에 업데이트할 수 있습니다.

## 0.2.0 변경

- 시작 화면과 첫 플레이 조작 안내. 안내를 읽는 동안 감시자 시간은 멈춥니다.
- 플레이 장면 확대, 주인의 뒷모습과 컴퓨터, 더 큰 고양이·물건 표시.
- 앞발 접촉 뒤에 물건이 움직이며, 선반 끝에서 낙하해 바닥에서 멈춥니다. 들키면 물건과 앞발이 그대로 멈춥니다.
- 초반 3개 장소의 뚜렷한 힘 구간과 손을 뗄 순간의 문구·진동·소리.
- 플레이 장면을 가리지 않는 결과창, 힘 부족/과다에 맞는 재도전 안내, 결과별 효과음.
- 원래 12개 장소의 규칙·힘 범위를 유지합니다.

현재는 초기 프로토타입이며 정식 아트·광고·결제는 포함하지 않습니다. 스토어용 서명이 아닌 테스트용 디버그 서명입니다.

Godot 엔진과 실제 OpenGL 화면에서 입력·규칙·진행·물건의 접촉/낙하에 대한 411개 검사를 통과했습니다. 내보낸 APK 안의 게임 리소스에서도 시작 화면과 12개 라운드를 확인했습니다. APK 서명·ZIP 무결성·16KiB 정렬을 확인했습니다. 실제 Android 휴대폰에서의 실행은 별도 확인이 필요합니다.

인터넷 권한을 포함하지 않습니다. 짧은 터치 진동을 위해 VIBRATE 권한을 포함합니다. SHA-256은 SHA256SUMS에 있습니다. 엔진 MIT 라이선스, 서드파티 고지 및 폰트 SIL OFL을 동봉합니다. 게임 소스 코드는 이 브랜치에 포함하지 않습니다.
