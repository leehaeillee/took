# 툭 · TUK Android 테스트 APK

버전: 0.1.0-dev · Android 7.0(API 24) 이상 · ARM 32/64비트

[TUK-debug.apk 다운로드](https://github.com/leehaeillee/took/raw/refs/heads/android-builds/TUK-debug.apk)

휴대폰에서 APK를 내려받아 열고, 요청되면 파일을 연 앱의 “알 수 없는 앱 설치”를 허용합니다.

사용자가 제공한 기획안을 바탕으로 만든 12개 스테이지의 초기 Godot 프로토타입입니다. 그림과 소리는 임시입니다. 광고·결제는 포함하지 않습니다. 스토어 배포용 서명이 아닌 디버그 서명을 사용합니다.

APK 서명, ZIP 무결성, 16KiB 정렬 및 게임 리소스의 데스크톱 Godot 실행을 확인했습니다. 실제 Android 기기에서의 실행은 아직 검증하지 않았습니다.

SHA-256은 SHA256SUMS에 있습니다. Godot Engine의 MIT 라이선스, 서드파티 고지 및 번들 폰트의 SIL OFL을 동봉합니다. 게임 소스 코드는 이 브랜치에 포함하지 않습니다.
